# Legacy Streamlit code

Original Streamlit dashboard from Phases 1-10. Archived 2026-06-01 when the
React rebuild (Phases 11-13) became primary.

Kept for reference. Not actively maintained. To run:
`streamlit run _legacy/streamlit_dashboard/Home.py` from the project root (most
imports still work because `modules/` and `core/` are unchanged), or
double-click `start_legacy_streamlit.bat`.
